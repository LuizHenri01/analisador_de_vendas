# Projeto 01 - Analisador de Vendas

## Objetivo

Projeto em desenvolvimento para praticar e relembrar fundamentos de Python aplicados à análise de dados.

## Conceitos praticados

- Listas
- Dicionários
- Laços `for`
- Condicionais
- Variáveis
- Funções
- Parâmetros e argumentos
- `return`
- Escopo de variáveis
- Acumuladores
- Comparação de valores
- Busca de maior e menor valor

## Funcionalidades

- Calcular faturamento total
- Calcular quantidade de vendas
- Calcular ticket médio
- Encontrar maior venda
- Encontrar menor venda
- Identificar o produto com maior venda
- Identificar o produto com menor venda

## Tecnologias

- Python
- Git
- GitHub
