# Analisador de Vendas

### Projeto de estudo em Python e Análise de Dados

Projeto desenvolvido com o objetivo de praticar, de forma progressiva, conceitos de **Python, manipulação de arquivos, tratamento de dados e análise de dados com Pandas**.

A ideia é evoluir o projeto gradualmente, adicionando novas tecnologias e tornando o processamento cada vez mais próximo de um cenário real de dados.

---

## Objetivos

* Praticar Python aplicado a dados
* Trabalhar com arquivos CSV
* Desenvolver funções reutilizáveis
* Aplicar validação e tratamento de erros
* Aprender Pandas na prática
* Realizar análises e agregações de dados
* Desenvolver boas práticas de organização de código
* Evoluir posteriormente para tecnologias utilizadas em Engenharia de Dados

---

## Tecnologias utilizadas

* **Python**
* **Pandas**
* **CSV**
* **Git**
* **GitHub**

---

## Funcionalidades atuais

O projeto atualmente é capaz de:

* Ler dados de vendas armazenados em CSV
* Validar os registros durante a leitura
* Identificar registros inválidos
* Converter valores para tipos numéricos
* Criar um DataFrame com Pandas
* Calcular o faturamento total
* Calcular a quantidade de vendas
* Calcular o ticket médio
* Identificar a maior venda
* Identificar a menor venda
* Ordenar as vendas por valor
* Exibir as 3 maiores vendas
* Agrupar vendas por produto
* Calcular quantidade de vendas por produto
* Calcular faturamento por produto

---

## Estrutura atual dos dados

Os dados são inicialmente armazenados em um arquivo CSV e posteriormente transformados em um DataFrame do Pandas para realização das análises.

Exemplo:

```csv
produto,valor
Notebook,3500
Mouse,120
Teclado,250
Monitor,1200
Headset,300
```
